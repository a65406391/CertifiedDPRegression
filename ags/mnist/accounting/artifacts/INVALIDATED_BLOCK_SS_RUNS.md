# Invalidated exploratory block-smooth-sensitivity runs

The following artifacts must not be interpreted as satisfying their stated
privacy target:

- `logistic_ags_tensor_l1_seed0.json`
- `logistic_ags_joint_l1_seed0.json`

They were generated by an initial prototype that reused the scalar
smooth-Laplace beta condition for a shared data-dependent scale in a
multidimensional block. That condition does not account for the dimensional
normalization term of the scaled block density. The implementation now rejects
this mode. Fixed-scale clipping-derived global-sensitivity block releases are
the valid block ablation.
